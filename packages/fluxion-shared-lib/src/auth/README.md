# Fluxion Enhanced Authentication System\n\nThe Fluxion Enhanced Authentication System provides a flexible, configurable, and powerful authentication and authorization framework for microservices. It supports multiple authentication methods, role-based access control (RBAC), permission-based access control, and both decorator-based and configuration-based route protection.\n\n## Table of Contents\n\n1. [Overview](#overview)\n2. [Key Features](#key-features)\n3. [Quick Start](#quick-start)\n4. [Configuration](#configuration)\n5. [Decorators](#decorators)\n6. [Middleware Usage](#middleware-usage)\n7. [JWT Token Structure](#jwt-token-structure)\n8. [Examples](#examples)\n9. [Migration Guide](#migration-guide)\n10. [API Reference](#api-reference)\n\n## Overview\n\nThe enhanced authentication system centralizes authentication logic in the shared package while allowing individual services to define their own access control policies. It supports:\n\n- **JWT-based authentication** with enhanced payload structure\n- **Role-based access control (RBAC)** with hierarchical roles\n- **Permission-based access control** with fine-grained permissions\n- **Decorator-based route protection** for clean, declarative security\n- **Configuration-based route protection** for runtime flexibility\n- **Rate limiting** and **audit logging**\n- **Multi-tenant organization support**\n- **Development mode** with authentication bypass\n\n## Key Features\n\n### 🔐 Multiple Authentication Methods\n- JWT Token Authentication (primary)\n- API Key Authentication (for integrations)\n- Wallet Signature Authentication (fallback)\n- Development Mode (bypass for testing)\n\n### 🛡️ Authorization Mechanisms\n- Role-based access control\n- Permission-based access control\n- System admin privileges\n- Cross-organization access control\n- Custom authorization functions\n\n### 🎯 Flexible Configuration\n- Service-level default configurations\n- Route-specific overrides\n- Runtime configuration updates\n- Decorator-based declarations\n\n### 📊 Enhanced Features\n- Rate limiting per route\n- Audit logging for security events\n- JWT token revocation\n- Refresh token support\n- Session management\n\n## Quick Start\n\n### 1. Install and Import\n\n```typescript\nimport {\n  createAuthMiddleware,\n  SERVICE_CONFIGS,\n  Public,\n  RequireAuth,\n  RequirePermissions,\n  RequireRoles\n} from '@fluxion/shared-lib';\n```\n\n### 2. Basic Express Setup\n\n```typescript\nimport express from 'express';\nimport { createAuthMiddleware, SERVICE_CONFIGS } from '@fluxion/shared-lib';\n\nconst app = express();\n\n// Use predefined service configuration\nconst authMiddleware = createAuthMiddleware(SERVICE_CONFIGS.MAIN_SERVICE);\n\n// Apply global auth middleware\napp.use(authMiddleware());\n\n// Your routes here...\napp.get('/api/protected', (req, res) => {\n  // req.auth contains the authentication context\n  res.json({ user: req.auth?.userId });\n});\n```\n\n### 3. Using Decorators\n\n```typescript\nexport class UserController {\n  @Public()\n  async getPublicData(req: Request, res: Response) {\n    // No authentication required\n  }\n\n  @RequireAuth()\n  async getProfile(req: Request, res: Response) {\n    // Authentication required\n    const auth = req.auth!;\n  }\n\n  @RequirePermissions(['user:manage'])\n  async updateUser(req: Request, res: Response) {\n    // Requires 'user:manage' permission\n  }\n\n  @RequireRoles(['admin', 'owner'])\n  async getAdminData(req: Request, res: Response) {\n    // Requires 'admin' OR 'owner' role\n  }\n}\n```\n\n## Configuration\n\n### Service Configuration\n\nCreate a service-specific configuration:\n\n```typescript\nimport { ServiceAuthConfig, createServiceConfig, ROUTE_PATTERNS } from '@fluxion/shared-lib';\n\nconst MY_SERVICE_CONFIG: ServiceAuthConfig = createServiceConfig('MY_SERVICE', {\n  defaultAuth: {\n    requireAuth: true,\n    optional: false\n  },\n  \n  publicRoutes: [\n    '/health',\n    '/docs',\n    '/api/auth/*'\n  ],\n  \n  routeConfigs: {\n    'GET /api/users': ROUTE_PATTERNS.USER_READ,\n    'POST /api/users': ROUTE_PATTERNS.USER_MANAGE,\n    'GET /api/admin/*': ROUTE_PATTERNS.ADMIN_ONLY,\n    'POST /api/payments': {\n      requireAuth: true,\n      permissions: {\n        permissions: ['payment:process'],\n        organizationSpecific: true\n      },\n      rateLimit: {\n        windowMs: 60000,\n        max: 10\n      }\n    }\n  },\n  \n  options: {\n    jwtSecret: process.env.JWT_SECRET,\n    jwtExpiresIn: '24h',\n    developmentMode: process.env.NODE_ENV === 'development'\n  }\n});\n```\n\n### Predefined Route Patterns\n\nUse predefined patterns for common scenarios:\n\n```typescript\nimport { ROUTE_PATTERNS } from '@fluxion/shared-lib';\n\nconst routeConfigs = {\n  'GET /api/invoices': ROUTE_PATTERNS.INVOICE_READ,\n  'POST /api/invoices': ROUTE_PATTERNS.INVOICE_WRITE,\n  'DELETE /api/invoices/:id': ROUTE_PATTERNS.INVOICE_DELETE,\n  'GET /api/admin/users': ROUTE_PATTERNS.ADMIN_ONLY,\n  'GET /api/system/stats': ROUTE_PATTERNS.SYSTEM_ADMIN,\n  'GET /api/analytics': ROUTE_PATTERNS.ANALYTICS_READ\n};\n```\n\n## Decorators\n\n### @Public(optional?)\n\nMarks a route as public (no authentication required).\n\n```typescript\n@Public() // No auth required\nasync getPublicData() { }\n\n@Public(true) // Optional auth (populate context if present)\nasync getOptionalAuthData() { }\n```\n\n### @RequireAuth(config?)\n\nRequires authentication for the route.\n\n```typescript\n@RequireAuth()\nasync getProtectedData() { }\n\n@RequireAuth({ \n  rateLimit: { windowMs: 60000, max: 10 } \n})\nasync getLimitedData() { }\n```\n\n### @RequirePermissions(permissions, options?)\n\nRequires specific permissions.\n\n```typescript\n@RequirePermissions('invoice:read')\nasync getInvoice() { }\n\n@RequirePermissions(['invoice:write', 'payment:process'], {\n  requireAll: true, // Must have ALL permissions\n  organizationSpecific: true\n})\nasync processInvoicePayment() { }\n```\n\n### @RequireRoles(roles, options?)\n\nRequires specific roles.\n\n```typescript\n@RequireRoles('admin')\nasync getAdminData() { }\n\n@RequireRoles(['admin', 'owner'], {\n  requireAll: false, // Must have ANY of these roles\n  organizationSpecific: true\n})\nasync manageUsers() { }\n```\n\n### @RequireSystemAdmin()\n\nRequires system administrator privileges.\n\n```typescript\n@RequireSystemAdmin()\nasync getSystemStats() { }\n```\n\n### @CustomAuth(handler)\n\nUses a custom authorization function.\n\n```typescript\n@CustomAuth(async (req, res, auth) => {\n  // Custom logic here\n  const resourceId = req.params.id;\n  return await checkResourceOwnership(auth.userId, resourceId);\n})\nasync getOwnedResource() { }\n```\n\n### @RateLimit(windowMs, max, options?)\n\nApplies rate limiting to a route.\n\n```typescript\n@RateLimit(60000, 10) // 10 requests per minute\nasync processPayment() { }\n```\n\n## Middleware Usage\n\n### Global Middleware\n\n```typescript\nimport { createAuthMiddleware } from '@fluxion/shared-lib';\n\nconst authMiddleware = createAuthMiddleware(serviceConfig);\napp.use(authMiddleware());\n```\n\n### Route-Specific Middleware\n\n```typescript\nimport { simpleAuth, withAuth } from '@fluxion/shared-lib';\n\n// Simple auth with default settings\napp.get('/api/protected', \n  simpleAuth(), \n  (req, res) => { /* handler */ }\n);\n\n// Auth with specific permissions\napp.get('/api/admin', \n  simpleAuth({ permissions: ['admin:read'] }),\n  (req, res) => { /* handler */ }\n);\n\n// Custom auth configuration\napp.post('/api/complex',\n  withAuth({\n    requireAuth: true,\n    permissions: {\n      permissions: ['resource:write'],\n      organizationSpecific: true\n    },\n    rateLimit: {\n      windowMs: 300000,\n      max: 5\n    }\n  }),\n  (req, res) => { /* handler */ }\n);\n```\n\n## JWT Token Structure\n\n### Enhanced JWT Payload\n\n```typescript\ninterface EnhancedJWTPayload {\n  // User identification\n  user_id: string;\n  wallet_address: string;\n  \n  // Organization context\n  organization_id?: string;\n  organization_name?: string;\n  organization_slug?: string;\n  \n  // RBAC data\n  roles?: string[];\n  permissions?: string[];\n  \n  // Legacy compatibility\n  role?: string;\n  \n  // System privileges\n  isSystemAdmin?: boolean;\n  canCrossOrganizations?: boolean;\n  \n  // Token metadata\n  iat: number;\n  exp: number;\n  jti?: string; // For revocation\n}\n```\n\n### Token Generation\n\n```typescript\nimport { generateEnhancedJWT } from '@fluxion/shared-lib';\n\nconst token = generateEnhancedJWT({\n  user_id: 'user_123',\n  wallet_address: '0x1234...5678',\n  organization_id: 'org_456',\n  organization_name: 'My Company',\n  roles: ['admin', 'member'],\n  permissions: ['invoice:read', 'invoice:write', 'user:manage'],\n  isSystemAdmin: false,\n  canCrossOrganizations: false\n}, {\n  expiresIn: '24h',\n  includeJti: true // For revocation support\n});\n```\n\n### Token Verification\n\n```typescript\nimport { verifyEnhancedJWT } from '@fluxion/shared-lib';\n\ntry {\n  const payload = verifyEnhancedJWT(token);\n  // Use payload data\n} catch (error) {\n  // Handle invalid token\n}\n```\n\n## Examples\n\n### Complete Express Application\n\n```typescript\nimport express from 'express';\nimport { \n wallet_address, signature } = req.body;\n  \n  // Verify signature (implementation depends on your setup)\n  // ...\n  \n  const token = generateEnhancedJWT({\n    user_id: Here's how to migrate:\n\n#### 1. Update Imports\n\n```typescript\n// Old\nimport { authenticateJWT, generateJWT } from '@fluxion/shared-lib';\n\n// New (backward compatible)\nimport { \n  authenticateJWT, // Still works\n  generateJWT, // Still works\n  createAuthMiddleware, // New enhanced middleware\n  generateEnhancedJWT, // New enhanced token generation\n  RequireAuth // New decorators\n} from '@fluxion/shared-lib';\n```\n\n#### 2. Gradual Migration\n\n```typescript\n// Phase 1: Use new middleware with existing routes\nconst authMiddleware = createAuthMiddleware();\napp.use(authMiddleware({ optional: true })); // Won't break existing routes\n\n// Phase 2: Update individual routes\napp.get('/api/new-endpoint', \n  simpleAuth({ permissions: ['resource:read'] }),\n  handler\n);\n\n// Phase 3: Use enhanced JWT for new tokens\nconst enhancedToken = generateEnhancedJWT({\n  user_id: user.id,\n  wallet_address: user.wallet,\n  roles: user.roles,\n  permissions: user.permissions\n});\n```\n\n#### 3. Update JWT Generation\n\n```typescript\n// Old\nconst token = generateJWT({\n  wallet_address: user.wallet,\n  user_id: user.id,\n  organization_id: user.orgId,\n  role: user.role\n});\n\n// New\nconst token = generateEnhancedJWT({\n  user_id: user.id,\n  wallet_address: user.wallet,\n  organization_id: user.orgId,\n  organization_name: user.organization.name,\n  roles: user.roles, // Array instead of single role\n  permissions: user.permissions,\n  isSystemAdmin: user.isSystemAdmin,\n  canCrossOrganizations: user.canCrossOrganizations\n});\n```\n\n## API Reference\n\n### Types\n\n- `AuthContext` - Authentication context attached to requests\n- `EnhancedJWTPayload` - Enhanced JWT token payload structure\n- `ServiceAuthConfig` - Service-level authentication configuration\n- `RouteAuthConfig` - Route-specific authentication configuration\n- `PermissionRequirement` - Permission-based access control configuration\n- `RoleRequirement` - Role-based access control configuration\n\n### Functions\n\n- `createAuthMiddleware(config?)` - Create authentication middleware\n- `generateEnhancedJWT(payload, options?)` - Generate enhanced JWT token\n- `verifyEnhancedJWT(token)` - Verify and decode enhanced JWT token\n- `createServiceConfig(name, config)` - Create custom service configuration\n- `simpleAuth(options?)` - Simple authentication middleware\n- `withAuth(config)` - Custom authentication middleware\n\n### Decorators\n\n- `@Public(optional?)` - Mark route as public\n- `@RequireAuth(config?)` - Require authentication\n- `@RequirePermissions(permissions, options?)` - Require permissions\n- `@RequireRoles(roles, options?)` - Require roles\n- `@RequireSystemAdmin()` - Require system admin\n- `@CustomAuth(handler)` - Custom authorization\n- `@RateLimit(windowMs, max, options?)` - Apply rate limiting\n\n### Configuration Constants\n\n- `SERVICE_CONFIGS` - Predefined service configurations\n- `ROUTE_PATTERNS` - Predefined route authentication patterns\n- `DEFAULT_AUTH_CONFIG` - Default authentication configuration\n\n---\n\n## Security Considerations\n\n1. **JWT Secret Management**: Use strong, unique JWT secrets per environment\n2. **Token Expiration**: Use appropriate expiration times (24h for access, 30d for refresh)\n3. **Rate Limiting**: Implement rate limiting on sensitive endpoints\n4. **Audit Logging**: Enable audit logging for security events\n5. **Permission Granularity**: Use fine-grained permissions instead of broad roles\n6. **Cross-Organization Access**: Carefully control cross-organization access\n7. **Development Mode**: Never use development mode in production\n\n## Support\n\nFor questions or issues with the authentication system:\n\n1.
